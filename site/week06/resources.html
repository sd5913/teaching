Open the two-second browser sound lab No Python, account or microphone: choose a 220 Hz tone or seeded noise, click Play, inspect the sample graph, and click Stop or press Escape. The page starts silent; set your device volume low before playing. The same instrument appears near the beginning of the slides.

The graph shows the samples sent to the browser audio buffer, not a microphone recording. If listening is uncomfortable or unavailable, compare the tone and noise graphs without pressing Play.

Start in the Strudel editor. Play the existing starter or an instructor-selected example, change one value, then stop it. The four links below each open a complete, cumulative score. Each next link restores the supplied baseline, so save or undo your experiment before adding the next layer.

Start with low device volume. Click Play or use Ctrl+Enter to start/update; click Stop or use Ctrl+. to stop. Stop before switching tabs or returning to the slides. These links never start sound automatically.

Read the small language

setcpm(100/4) gives 25 cycles/minute. Here a cycle is four beats at 100 BPM. *8 repeats eight times; ~ leaves a rest; [c3,e3,g3] places three notes together. stack combines the layers.

First sounds · First notes

1. Hi-hat

  s("hh*8").gain(.12),

2. Add bass

Open this stage in Strudel Download score

3. Add chords

  note("[c3,e3,g3]").s("sine").gain(.08),
  note("c4 e4 g4 b4").s("sine").gain(.12),
)

Make one change with an agent

  1. Keep a copy of the four-layer score. Predict a change to rhythm, register, harmony or melody.
  2. In the current Easel client, create a fresh project, then Templates → Strudel sound. Older projects can retain older sample kits.
  3. Paste the complete score, then press Run. Ask the agent: “Change only the melody to feel more spacious. Keep the tempo and other three layers. Explain the edit and preserve my starting version.”
  4. Listen, inspect the code, compare, then Stop or Escape. If the local hi-hat is unavailable, continue in strudel.cc or omit that layer while checking the installed kit.
  5. Keep the before/after score and one sentence about the effect. The native oscillators and bundled drums avoid remote sample banks; their timbre need not match the website.

Python examples

Download the helper beside both examples. In that folder run python noise.py or python tone.py. Each writes a two-second WAV without playing it.

  • wav_support.py — shared standard-library file writer
  • noise.py — seeded random samples
  • tone.py — frequency and amplitude
  • request_song.py — offline JSON preview by default
  • Song API contract and instructor preflight

The song API needs a separate configured service for a live request. The teacher serializes any live demo. Students do not need an account for this lesson.
