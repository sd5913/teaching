# Delivered decks

The PowerPoint actually shown in class, as delivered, one file per week. These are
**not** generated from `deck/` — they predate this repo.

| File | Slides | ClassPoint | Built with |
|---|---|---|---|
| `SD5913-week01.pptx` | 64 | 7 | **PptxGenJS**, then given the ait4x theme, master and 6 layouts (Title, Section band, Content white, Content ink, Two column, Question) plus a row-by-row entrance animation on every slide. |

Week 1 is kept because the delivered file is the historical record — what the room saw,
including whatever changed in the last ten minutes. Its generator is **not in this repo
and not on the teaching box**; the file is the only artifact.

> Two earlier accounts of how this deck was made are wrong and worth not repeating: it is
> not the 19 MB hand-built deck in `~/dev/sd5913/`, and it was not produced by
> `~/dev/sd5913/deck/restyle.py` rewriting `theme1.xml` in place. `docProps/core.xml`
> says PptxGenJS, created 2026-09-02, last modified 2026-09-03.

Anything from week 2 on is generated by [`ait4x/deckgen`](https://github.com/ait4x/deckgen),
so its source of truth is `deck/weekNN.py` and nothing needs to land here unless the file
was edited live in the room.

Keep an eye on repo size, and never add a deck here that the generator already produces.

## What week 1 covered

Why are we here · artists and designers · is programming an art (Nake, *Homage to Paul
Klee*; Molnár; Lovelace and the Analytical Engine) · is programming a craft · mediated
perception · the five assessment components and three repos · the programmer's mindset
(Turing machines, kernel and shell, the terminal, package managers) · languages, syntax,
compiled vs interpreted · Python and the Zen · tools for the job (uv, VS Code, git and
GitHub, issue → fork → commit → pull request) · data visualisation and the tides example ·
**Design the mark** (the 1-2-4-All, slides 53–57) · the two-hour tutorial.

**Design the mark did not run — the room ran out of time.** It is carried into week 2,
ported into `deck/week02.py` from these slides rather than rewritten.
