# Delivered decks

The PowerPoint actually shown in class, as delivered, one file per week. These are
**not** generated from `deck/` — week 1 was built by hand and restyled in place with
the old `~/dev/sd5913/deck/restyle.py`, before this repo existed.

Kept because the delivered file is the historical record: what the room saw, including
whatever was changed in the last ten minutes. Anything from week 2 on is generated, so
its source of truth is `deck/weekNN.py` and this folder only holds a copy if the file
was edited live.

Large binaries — keep an eye on the repo size, and do not add a deck here that the
generator already produces byte-for-byte.
