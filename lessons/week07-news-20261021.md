# Week 7 news brief — 21 October 2026

Instructor-ready update for SD5913. Use at most a short opener or tutorial bridge **after the fixed midterm**, without reducing quiz time or replacing the agreed team activities. These are current news examples, not new assessed material. No paid account or new installation is required; an existing local project and prepared outputs are sufficient.

## 1. Behavior, not just runnable code

**Event: 19 October 2026.** OpenAI released MultiLangBench, an evaluation of SQLite-compatible implementations across 20 languages. Reported results are vendor evidence, not an independent reliability guarantee. The released evaluation code is distinct from model weights. [Primary release](https://openai.com/index/low-resource-programming-languages/) · [evaluation repository](https://github.com/openai/MultiLangBench).

**Question:** What test would catch a rewrite that runs but changes the result?

**Small demonstration:** Take a familiar function from a team prototype. Specify normal, empty and boundary inputs before asking for a rewrite. Compare observable outputs. A successful demonstration is evidence about that function and those tests, not the whole agent.

## 2. Faster text is not necessarily a faster task

**Event: 15 October 2026.** Claude Opus 5.5 fast mode became generally available for eligible API tiers. The vendor advertises up to 2.5× output-token speed, not equivalent end-to-end speed. Premium pricing, separate rate limits and account eligibility apply. [Release notes](https://platform.claude.com/docs/en/release-notes/overview) · [fast-mode documentation](https://platform.claude.com/docs/en/build-with-claude/fast-mode).

**Question:** If most time is spent running tools or tests, what would faster generation change?

**Small demonstration:** Annotate an existing task trace as model output, tool execution, test execution and correction. Do not require purchasing fast mode to discuss the bottleneck.

## 3. Compare cost per successful result

**Event: 19 October 2026.** MiniMax launched M3.1 Flash through its hosted API, M Plan and MiniMax Code. The announcement lists $0.15 input/$0.60 output per million tokens; near-threefold inference speed and 70% lower agent cost are vendor claims. Weights were promised later, not released as open weights or open-source software in this announcement. [Primary release](https://www.minimax.io/blog/minimax-m31f).

**Question:** Can the cheaper model become more expensive after retries and manual fixes?

**Small demonstration:** Compare two already available runs on the same small task and tests. Record successful output, retries, tool time and stated cost. If no comparable runs exist, use a clearly labelled hypothetical table, not invented measurements.
