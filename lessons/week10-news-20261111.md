## 1. Search and a wiki can support different memory jobs

Anthropic published [Components of agent memory](https://www.anthropic.com/research/components-of-agent-memory)
on 6 November. In its particular evaluation, the reported scores were 53%
with search alone, 48% with a wiki alone and 61% with both. These are vendor
research results for the evaluated system and tasks, not general success rates,
independent replication or evidence that every agent needs this architecture.

**Course connection:** return to the four kinds of state. The shared handbook
and its index supply policy evidence; User/Conversation/Message rows retain a
particular user's history; the next prompt contains a selected working context;
audio is an output. A saved conversation ID alone does not establish that the
right history reached the model. Our existing handbook example is not a
reproduction of Anthropic's research system.

**Two-minute opening option:** use this instead of, not in addition to, the
older Peewee release example inside the existing 0-10-minute opening. Ask:
"If the bot remembers that Ada lost a card, does that tell it the current
replacement policy?" Point to one history row and one cited handbook passage.
Then ask what happens when an old remembered detail conflicts with the current
source. Keep the original four-state explanation and lesson route.

## 2. A persistent bot still needs an access boundary

Kiro announced [Crew bots](https://kiro.dev/blog/crew-bots/) on 5 November.
The [operating documentation](https://kiro.dev/docs/crew/bots/how-bots-work/)
describes persistent bots, scheduled operation through a gateway and credit
usage. Bots are generally available, but this does not establish access for
every student or a free service. Trust mode is the default; the configured
workspace is not a filesystem security boundary.

**Optional discussion only:** draw "stored history / current task / allowed
tools / approval / result evidence" around a fictional handbook assistant.
Which operation is a read, and which changes something for another person?
Persistence is neither permission nor proof that an action completed. Do not
install Kiro, enable a gateway, connect an account or run an autonomous bot in
class for this news item.
