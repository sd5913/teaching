# Week 9 opening source: when a default changes

Verified 29 October 2026 via GitHub MCP's upstream latest-release response.
Use at most three minutes in the opening, then refresh before 5 November.

Primary source: [FastAPI 0.162.0 release](https://github.com/fastapi/fastapi/releases/tag/0.162.0),
published 23 October 2026 at 18:47 UTC. It changes omitted boolean form-field
handling to use declared defaults or missing-field errors, consistent with
other fields/Pydantic. Omitted checkboxes should declare a False default.
This release is a current example of an interface contract changing; no
claim about observed student apps or production incidents is made.

Ask: if a gallery control does not send a field, should the artwork interpret
that as False, unchanged, or invalid? Who defines that behavior? Connect the
answer to explicit validation of the later JSON set_x message. Our example
uses JSON, not this affected form-field pathway, so do not imply its behavior
changed because of this particular fix. Show the primary release date/link.

This is dated news and a design prompt, not quiz scope or a mandate to rebuild
a project. Release numbers/default changes are not facts to memorize. The
latest release target was subsequently installed and accepted with real
network/browser checks on29October; reading release notes alone would not
establish compatibility.
