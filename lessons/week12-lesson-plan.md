# Week 12 · Programming concepts and subject AMA

Thursday 26 November 2026, Hong Kong. The 120-minute lecture revisits all eleven taught weeks and looks at one bounded agent loop. The final ten-minute eSFQ slot is followed by an open AMA about the subject material. The separate [student tutorial](https://github.com/sd5913/pfad/blob/92061c101aed3a83a4708a7e07766db8571ee197/week12/README.md) focuses on group-project delivery, peer trials and iterative refinement. Concept prompts and the Godot exercise are optional references.

Students should be able to explain how a rule turns data into an experience, predict what persists after a disconnect or restart, and identify what evidence supports a result at each system boundary. Use the definitions, notation and workflows on the slides as a reference. Select a prediction to discuss in each block. Use the local PDF and paper if the classroom tool or network is unavailable.
